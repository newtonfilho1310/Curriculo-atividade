# Atividade de HTML — Currículo

Página de currículo de Newton Pinto Filho desenvolvida em HTML e CSS para a atividade do professor Crispim.

## Como visualizar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

## Recursos

- Layout responsivo com aparência de terminal.
- Seções de objetivo, experiência, formação, habilidades e contato.
- Foto de perfil e navegação entre as seções.
- Estilos para impressão e recursos de acessibilidade.

## Arquivos

- `index.html`: página e estilos do currículo.
- `805d115a-20ee-465e-b81c-53d9bd28b8be.jpg`: foto utilizada na página.

Os PDFs usados como material de referência permanecem apenas na pasta local.
